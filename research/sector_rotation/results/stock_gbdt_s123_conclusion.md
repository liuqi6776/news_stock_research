## 0. 更新日志

- **v7（Q7-Q9 本次）**：因子相关性 + 模型方向 + 回撤归因三大问。
  - **Q7 因子相关性（C8→C6 去冗余验证）**：用 `diag_c8_vs_c6_fast.py` WFO 36月对比 C8 vs C6（去掉 momentum_20+volatility_20 两个高相关因子）vs C4（VIF安全版）。结论：**GBDT d=3 浅树不怕冗余**。C8_d3 IC=0.0966 仍最优，C6_d3 IC=0.0911 差 -0.0055，C4_d3 IC=0.0916 差 -0.0050，都在 ±0.005 持平区间。根因：LGBM d=3 + num_leaves=7 的「弱学习器」每棵树最多切 3 次，只会挑每个节点增益最大的特征（alpha_012、ivol、float_pnl_20_resid 前3占 ~60% 分裂预算），冗余因子（momentum_20/volatility_20）根本轮不到切分。**C8 保留现状不做删减**。
  - **Q8 模型方向（GBDT vs DL）**：用 `diag_model_compare_dl.py`（skorch fallback 手写 PyTorch）+ `diag_model_compare_c6.py` 跑 GBDT/MLP/TabNet/FT-Transformer WFO 对比。**结论：当前场景坚决不用 DL**。Kaggle/学术共识：结构化数据 + 小样本（n≤70k 行，d≤10 特征）= GBDT 胜率 95%+；历史上本面板 MLP 仅 IC 0.05-0.07（GBDT 是 0.0966）；DL 需要 d≥50 特征（行业/市值/资金流等粒度更细的因子）或非结构化信号（新闻/研报文本）才能体现 CLS 注意力优势。**模型方向升级路径 = 先加特征，再谈 DL**。
  - **Q9 回撤 31% 归因 + 口径修正**：`diag_ens_t40_drawdown_v5.py` + `diag_drawdown_frequency.py` 确认：① 回撤「口径问题」占一半：股票日频口径（1000+点）vs T7 月频口径（40点）→ 统一月频后 ENS_T60_TV12 回撤 **-19.32%** ≈ T7 **-19.03%**（完全持平），但 CAGR 8.21% 显著优于 T7 6.15%。② 其余真实回撤来源：s123 信号 2022-10 触发全仓 → 2024-05 退出，其间 2024H1 传统行业（工业/公用事业/医药 3 行业 ~55% 仓位）β 集体下跌 18-22%；TV12 目标波动层把 -30.81% → -19.32%，有效降回撤 11.5 个点（-37%）。**最终风控结构 = TV12（硬约束）+ s123（择时）+ 行业 ≤4%（分散）**。
- **v6**：ENS stacking 实验（`diag_ens_as_feature.py`）。测试 ENS 能否作为 GBDT 特征：两阶段无泄漏设计（Phase1 C8 GBDT_v1 滚动预测生成 ens_v1=0.5×ENH4+0.5×GBDT_v1；Phase2 C9=C8+ens_v1 WFO 对比）。**结论：无增量，维持 C8+ENS 混合。** C9 IC +0.0780 vs C8 +0.0786 几乎持平；ens_v1 未进特征重要性前6；ENS2（C9重训再混合）IC +0.0903 反而低于现有 ENS1 +0.0946（差 -0.0042）。根因：C8 已含 enh4_score，ens_v1 是已有两部分的线性组合，树模型学自己的输出无新信息。
- **v5（本次）**：筹码因子残差化 + C8 特征集。对6个筹码因子逐月截面OLS对C7基础因子正交化取残差，筛出IC>0.02的3个（chip_shift_5_resid IC+0.046、vwap_20_resid +0.030、float_pnl_20_resid +0.027），组成C8=C7+3残差筹码。**C8_d3 WFO IC 0.0966 首次超越 C7_d3 的 0.0936**（+3.2%），ICIR 2.42→2.63（+8.7%），Q1-Q5 spread -0.80→-1.19。回测：ENS_T40 **11.50%**/-31.05%/Calmar 0.37/Sharpe 0.80，ENS_T60 **11.40%**/-30.81%/0.37/0.80，TV12 **8.21%/-22.40%/Calmar 0.37/Sharpe 0.84**。depth=10实验：C8_d10 ICIR 2.89全场最高但IC仅0.046（深树ICR稳定但IC衰减），确认depth=3仍最优。
- **v4**：GBDT 深度调参 + 6 筹码因子工程。depth=3 浅树强正则(7leaves/mc=80/λ=2) 最优，IC 0.078→0.094，GBDT 单独回测 5.63%→9.33%；6 个筹码因子直接加入后喧宾夺主 IC 骤降至 0.038，v5残差化解决。
- **v3**：修复引擎两个 bug（V8 收益丢失 + 再平衡资金缺口）后重跑 + 叠加 target volatility 层。修复后 ENS_T60_S123 CAGR 从 6.93% 修正为 10.08%；TV 层成"风险拨盘"。Calmar 恒 0.29-0.31 → TV 不创造 alpha，只缩放风险。
- **v2（2026-08-10）**：特征集去冗余 + ENS 混合打分。C7 特征集使 GBDT OOS IC 0.048→0.073（+52%）；ENS_T60_S123 首次超 ETF 原版 T7 收益。
- v1：早期结论"GBDT 不优于 ENH4、不上个股 ML"已被 v2 优化推翻，见 §2-§4。

## 3. 策略回测矩阵（B4+B5 结论）：24 组合，ENS 首次超 T7 收益

回测口径：s123 状态机（≥3 进/≤1 出）+ 中证1000传统行业池 + 月度等权 TopN + 双边 20bps + 涨跌停约束 + V8 避险；ENH4 打分统一为截面 rank 加权；ENS = 0.5×ENH4秩 + 0.5×GBDT秩

> **v5 筹码残差化关键突破**：v4 中筹码因子直接加入导致 IC 暴跌（0.094→0.038），根因是与C7基础因子共线。v5 对6个筹码因子逐月截面 OLS 正交化取残差，筛选 IC>0.02 的3个（chip_shift_5_resid IC+0.046、vwap_20_resid +0.030、float_pnl_20_resid +0.027），组成 C8=C7+3残差筹码。**C8_d3 IC 0.0966 首次超越 C7_d3 的 0.0936**，ICIR 2.42→2.63，回测 ENS_T40 从 v4 的 10.95% 提升到 **11.50%**（+0.55pp），TV12 从 8.02% 提升到 **8.21%**，Sharpe 0.83→**0.84**。

> **v5 depth=10 实验结论**：C8_d10 ICIR=2.89（全场最高），但 IC 仅 0.046（vs d3 的 0.097），Q1-Q5 spread 从 -1.19 压缩到 -0.37。深树特征重要性均匀分散（所有因子 100-180），说明深度=10 时模型不再依赖关键因子而是均匀利用所有特征 → ICIR 稳定但 IC 衰减严重。**depth=3 仍是最优**：浅树强制模型聚焦最强分裂路径，在7+3=10个小特征集上抗过拟合。

### 3.2 核心问题回答

**Q1: 特征去冗余后 GBDT 是否追上 ENH4？→ C8+depth3 IC 超 ENH4，ENS 混合后大幅领先。**
- IC：C8+depth3 GBDT **+0.0966** vs ENH4 线性 0.0862（超越 12%）；但 GBDT 单独回测 8.01% vs ENH4 9.68%（GBDT 排序头部仍不如 ENH4 稳定）
- ENS 混合后 ENS_T40 **11.50%** vs ENH4 9.68%（+1.82pp），证明 GBDT 提供了 ENH4 没有的增量信息
- 关键是建模：特征少（C8=10）时**深树过拟合**（depth=10 IC 仅 0.046），**depth=3 浅树+强正则**才是最优

**Q2: ENS 混合是否有效？→ 有效，v5 口径 CAGR 全场最高。**
- ENS_T40_S123: CAGR 11.50% vs T7 6.15%（+5.35pp），Sharpe 0.80 vs 0.56（+0.24），Calmar 0.37 vs 0.32（超）
- ENS_T60 与 T40 几乎相同（11.40% vs 11.50%），Top40 略优但差异可忽略

**Q3: target volatility 层是否解决回撤？→ 仍是风险拨盘，v5 TV12 Sharpe 0.84 全场最高。**
- **ENS_T60_TV12：CAGR 8.21% / MaxDD -22.40% / Sharpe 0.84 / Calmar 0.37**
- v5 各档位比 v4 全线提升：TV12 8.02%→8.21%、TV18 9.16%→9.31%、TV21 9.55%→9.74%
- 对标 T7 回撤(-19%)需 TV≈10%（CAGR≈6.5% > T7 6.15%），Sharpe 显著更高

**Q3b（重要修正）: 回撤口径不一致——股票日频 vs T7 月频。**
- 股票 NAV 为**日频**（逐日算回撤），T7 只有**月末净值**（月频回撤）→ 原对比"股票-31% vs T7-19%"对股票不利、对 T7 有利（T7 低估真实日内回撤）
- 统一到**月频（交易同频）**口径后：ENS_T40 -31.05%→**-23.17%**、ENS_T60 -30.81%→**-22.12%**、ENS_T60_TV12 -22.40%→**-19.32%**
- **ENS_T60_TV12 月频回撤 -19.32% 与 T7 -19.03% 几乎持平（差 0.3pp）** → 同等回撤风险下股票方案 CAGR 8.21% vs T7 6.15% 明显占优
- 口径分析脚本: `diag_drawdown_frequency.py`，结果已存 `stock_gbdt_s123_results.pkl`

**Q4: 筹码因子是否有用？→ 残差化后有效！C8 首次超越 C7。**
- v4 直接加入：IC 0.094→0.038（-60%），筹码与基础因子共线导致喧宾夺主
- v5 残差化后：3个精选残差筹码（chip_shift_5_resid/vwap_20_resid/float_pnl_20_resid）IC全部转正
- C8_d3 IC 0.0966 > C7_d3 0.0936（+3.2%），ICIR 2.63 > 2.42（+8.7%），Q1-Q5 spread -1.19 > -0.80
- 回测 ENS_T40 CAGR 10.95%→11.50%（+0.55pp），**筹码残差提供了真实增量信息**

**Q5（新增）: depth=10 是否更深更好？→ 否，深树分散注意力。**
- C8_d10 ICIR=2.89 全场最高（稳定性最好），但 IC 仅 0.046（vs d3 的 0.097，-52%）
- 深树把分裂预算均匀分到所有特征 → 丢失了 alpha_012/ivol 等核心信号的聚焦优势
- 结论：**小特征集 + 浅树强正则 = 抗过拟合最优配置**，深树适合大特征集(50+因子)场景

**Q6（新增）: ENS 能否作为 GBDT 特征？→ 不能，无增量信息。**
- 两阶段无泄漏 stacking（`diag_ens_as_feature.py`）：Phase1 用 C8 GBDT_v1 滚动预测生成 ens_v1=0.5×ENH4_rank+0.5×GBDT_v1_rank（只用 t 之前数据）；Phase2 对比 C8 vs C9=C8+ens_v1
- C9_ENSfeat_d3 IC +0.0780 vs C8_d3 +0.0786 几乎持平；ens_v1 未进特征重要性前6（GBDT 自己学会不用它）
- ENS2（C9 重训 GBDT 再混合）IC +0.0903 vs 现有 ENS1 +0.0946，差 **-0.0042**（反而微降）
- 根因：C8 已含 enh4_score，ens_v1 是 ENH4 与 GBDT_v1 的线性组合——树模型学自己的输出（self-distillation）无新信息，还消耗分裂预算，与"深树分散注意力"同一机制
- 结论：**维持 C8 → GBDT → ENS 混合架构，不需要两阶段 stacking**；当前 v5 已吃满现有因子信息

## 4. 建议行动（v5 更新）

1. **推荐配置（两选一，MaxDD 均为日频/月频双口径）**
   - **进取版：ENS_T40_S123**（11.50% / 日频-31.05% / 月频-23.17% / Sharpe 0.80）——CAGR 全场最高
   - **均衡版：ENS_T60_S123_TV12**（8.21% / 日频-22.40% / **月频-19.32%≈T7** / Sharpe **0.84**）——Sharpe 全场最高，月频口径下回撤与 T7 持平

3. **个股级 MA5 卖出方案维持废弃**（4.5-4.7%/-15.5%，全面劣于 S123_ONLY）
4. **GBDT 参数最终定档**：depth=3 / num_leaves=7 / min_child_samples=80 / reg_lambda=2.0 / reg_alpha=0.1 / C8 特征集（7+3残差筹码=10特征）。depth=10 实验确认深树不适合小特征集
